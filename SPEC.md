# SPEC: сайт кофейни «Горький» (Нальчик, 4 точки)

Заменяет текущий сайт https://gorkiynalchik.ru (сделан на Tilda). Бренд и атмосферу сохраняем, добавляем заказы, профили и админку.

## Цель
Минималистичный сайт, где клиент выбирает точку, собирает заказ и платит на месте при получении, а бариста именно этой точки мгновенно получает заказ в свой Telegram-чат.

## Пользователи
- **Клиент**: регистрируется, выбирает точку, заказывает, видит историю, получает уведомления.
- **Бариста**: получает заказы своей точки в Telegram, меняет статус кнопками.
- **Админ (владелец)**: управляет всем меню и всеми точками.

- Заказ всегда принадлежит одной точке и уходит только в чат этой точки.

## Функции (MVP)
1. Выбор точки (при первом заходе окно выбора, потом переключатель в шапке вкладки «Меню»).
2. Меню: категории, позиции (название, цена, фото, описание), опции (объём, молоко, сироп). Показывается с учётом стоп-листа выбранной точки.
3. Корзина и оформление: время «к которому приготовить», комментарий.
4. Профиль: регистрация/вход (email или Telegram Login), имя, телефон, любимая точка.
5. История заказов: список, статусы, точка, «повторить заказ».
6. Оплата только на месте при получении: клиент выбирает «наличными» или «картой на терминале». Онлайн-оплаты на сайте нет.
7. Telegram бариста: новый заказ приходит в чат нужной точки с кнопками «Принял», «Готов», «Отменить». В сообщении указан способ оплаты (наличные или терминал), чтобы бариста заранее знал, чем будет расчёт.
8. Уведомления клиенту: смена статуса на сайте в реальном времени и в Telegram (если привязал).

## Админка
Вход только для админа. Вверху переключатель: **«Общее меню»** и **«Точка: A / B / C / D»**.

**Общее меню (редактируется всё):**
- Категории: создать, переименовать, порядок, удалить.
- Позиции: создать, удалить, название, описание, цена, фото (загрузка), категория, порядок, состав/КБЖУ (опционально).
- Опции и добавки: группы опций (молоко, сиропы, объём), цена каждой, привязка к позициям.
- Скрыть позицию везде (без удаления).

**Настройки точки:**
- Стоп-лист позиций и опций для этой точки.
- Своя цена на позицию (если пусто, берётся общая).
- Часы работы, адрес, вкл/выкл приём заказов.
- Telegram chat_id точки.
- Список текущих и прошлых заказов этой точки.

## Не делаем (пока)
- Доставка и курьеры
- Онлайн-оплата на сайте
- Лояльность, баллы, промокоды
- Мобильное приложение
- Отдельные роли для менеджеров точек (только админ и бариста)

## Статусы заказа
`new` → `accepted` → `ready` → `done` (или `cancelled`)

## Оплата
Только на месте при получении заказа:
- `cash`: наличными
- `card_terminal`: безналично через собственный терминал точки

Клиент выбирает способ при оформлении, бариста видит его в Telegram. Никаких платёжных провайдеров и интеграций не нужно. Если онлайн-оплата понадобится позже, поле `payment_method` можно расширить новыми значениями.

## Технологии (предложение)
- Next.js (TypeScript), Tailwind CSS
- Supabase: Postgres, авторизация, realtime, хранилище фото
- Telegram Bot API через webhook (один бот, много чатов: чат выбирается по точке)
- Vercel для хостинга

## Модель данных (черновик)
- `locations`: id, name, address, hours, telegram_chat_id, is_accepting_orders
- `profiles`: id, name, phone, telegram_chat_id, favorite_location_id, is_admin
- `categories`: id, name, sort_order
- `menu_items`: id, category_id, name, description, base_price, image_url, is_active, sort_order
- `option_groups` / `options`: группы и значения опций, price_delta, привязка к menu_items
- `location_item_settings`: location_id, item_id, is_available, price_override
- `location_option_settings`: location_id, option_id, is_available
- `orders`: id, user_id, location_id, status, payment_method (cash | card_terminal), total, pickup_time, comment, created_at
- `order_items`: id, order_id, item_id, quantity, options (json), price (цена на момент заказа)

## Дизайн
**Что сохраняем с текущего сайта:** название и логотип «ГОРЬКИЙ», тёплый уютный тон текстов («Согреваем гостей, заботимся о своих»), фото интерьеров и блюд, отзывы гостей, контакты точек.

**Что убираем (всё, что мешает):**
- Конструкторский «мусор» Tilda: лишние скрипты, тяжёлые блоки, тормозящую прокрутку
- Длинный одностраничный скролл с повторяющимися блоками
- Главную страницу с большим блоком «Хочу в команду»: остаётся одной мелкой ссылкой внизу вкладки «Профиль»
- Дублирующие заголовки и пустые секции
- Попапы и всё, что перекрывает контент

**Структура сайта: ровно две вкладки.** Отдельной главной страницы нет, сайт открывается сразу на вкладке «Меню».

Навигация: нижняя панель на мобильных (две кнопки с иконками), на десктопе те же две вкладки в шапке. Других пунктов меню и «бургера» нет.

1. **Вкладка «Меню»** (открывается по умолчанию): все продукты.
   - Сверху шапка: логотип и переключатель точки («Горький на Арбате» и т.д.)
   - Под шапкой горизонтальная полоса категорий (прилипает при прокрутке)
   - Все продукты списком по категориям: фото, название, короткое описание, цена, кнопка «+»
   - Нажатие на продукт открывает карточку с выбором опций и количества
   - Плавающая кнопка корзины с суммой (появляется, когда в корзине что-то есть), оформление заказа открывается из неё
   - Продукты показываются с учётом стоп-листа и цен выбранной точки
2. **Вкладка «Профиль»**:
   - Если не вошёл: форма входа/регистрации
   - Если вошёл: имя, телефон, любимая точка, кнопка выхода
   - История заказов (статус, точка, состав, сумма, «повторить заказ»)
   - Список точек с адресами и телефонами, кнопка «Маршрут» (Яндекс.Карты)
   - Внизу мелкой ссылкой «Хочу в команду» (WhatsApp +7 988 933-42-33) и юридическая строка «© GORKIY»

Админка живёт отдельно по адресу `/admin` и в эти две вкладки не входит.

### Логотип (обязательное требование)
Логотип должен быть **именно таким, как на текущем сайте**: тонкий геометрический шрифтовой знак «ГОРЬКИЙ» из одной линии (буква «Р» выглядит как открытая полукруглая скобка, «Ь» как широкая скобка с хвостом, над «Й» острый акцент).
- Готовый файл лежит в `assets/gorkiy_logo.png` (чёрный на прозрачном фоне, 670x103 px). Копируем в `public/logo.png`.
- Использовать ТОЛЬКО этот файл. Нельзя перерисовывать, набирать текстом, подбирать шрифт, менять пропорции, цвет, обводку или добавлять тени.
- Размер: высота 28-32 px на мобильных, до 40 px на десктопе, ширина по пропорции. Слева в шапке, клик ведёт на вкладку «Меню».
- Если нужен более чёткий вариант для больших экранов, запросить у владельца векторный файл (SVG), а не улучшать самим.

### Стиль (по скриншоту текущего сайта)
- Фон белый, текст почти чёрный (#111), второстепенный текст тёмно-серый
- Шрифт: геометрический гротеск без засечек (как Gilroy/Geometria). Подойдут Manrope или Montserrat. Заголовки жирные, обычный текст лёгкий
- Кнопки: белые с тонкой чёрной обводкой (2 px) и скруглением около 16 px, основная кнопка «Заказать/Оплатить» может быть чёрной с белым текстом
- Фото крупные, без рамок, с лёгким скруглением
- Много воздуха, отступы по бокам 16-20 px, никакого лишнего декора, анимации только короткие и тихие
- Сначала мобильная версия (ширина 375-430 px), потом адаптация под десктоп

**Нужно уточнить позже:** акцентный цвет (если нужен), список продуктов и фото для меню.

## Критерии готовности
- Клиент проходит путь «выбор точки → заказ → получение» без ошибок.
- Заказ приходит в чат ровно той точки, которую выбрал клиент, и больше никуда.
- Бариста меняет статус кнопкой, клиент видит его на сайте сразу.
- Нельзя заказать позицию из стоп-листа выбранной точки.
- Админ меняет фото, цену, описание, добавляет и убирает позиции, и это сразу видно на сайте.
